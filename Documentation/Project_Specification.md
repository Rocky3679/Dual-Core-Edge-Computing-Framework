# Project Specification

## Project Title

**Dual-Core Edge Computing Framework for Power Factor Correction and Load Demand Management**

---

## Project Type

Final Year B.E. Electrical and Electronics Engineering Team Project

---

## Problem Statement

Industrial and commercial electrical systems often suffer from poor power factor, uneven load distribution, and inefficient energy utilization. Conventional monitoring systems rely on centralized processing, resulting in delayed decision-making and reduced system responsiveness.

This project proposes an edge computing framework capable of performing local monitoring and intelligent decision-making for power factor correction and load demand management.

---

## Objectives

- Monitor electrical parameters in real time.
- Improve overall power factor.
- Manage electrical load demand efficiently.
- Perform edge-based processing to reduce response time.
- Enable intelligent energy management using embedded hardware.
- Demonstrate a scalable framework suitable for Industry 4.0 applications.

---
